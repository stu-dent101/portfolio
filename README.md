# Developer Portfolio

## Deployed application link

https://stu-dent101.github.io/portfolio/#top


## Run locally

From the project directory, install dependencies and start the Vite development server:

```powershell
npm install
npm run dev
```

Open the local URL shown in the terminal, usually [http://localhost:5173](http://localhost:5173).

## Production build

Create the production build:

```powershell
npm run build
```

Preview the production build locally:

```powershell
npm run preview
```
